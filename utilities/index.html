• These are the various scrapers, crawlers, and scripts used to build the datasets used for these charts. Each includes a preview of the script, a description of it's purpose, and instructions on how to use it.

    To download the script or copy to your clipboard, click the corresponding button at the bottom of the page.

    All necessary npm installs are included at the top of the file

  • Scrapes metadata fields for all productions currently on the GSVA website and compares to the current production table Excel sheet. It saves the result of this comparison as an Excel sheet and a JSON file.

    To use: download the file in the same directory as the current production table Excel sheet; run 'node prod-table.js'

  • Used to count the number of countries, regions, etc represented in the production table

    To use: download file in same directory as production table json; cd to directory and run 'node count.js'

  • Used to read Monster Insights reports and crossreference with GSVA website to create dataset used in bar chart

    To use: download file in same directory as the Monster Insights pdf report; run 'node pdf-crawl.js'; when prompted in your console, enter the month and year of the report
